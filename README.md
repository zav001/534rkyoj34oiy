# DonutClient Website

A standalone HTML/CSS/JS landing page inspired by the structure of the supplied Goobaa Client reference, with original DonutClient branding and a blue visual system.

## Files
- index.html — page structure/content
- style.css — responsive styling
- script.js — small navigation/scroll interactions

## Customize
1. Replace the GitHub URL in `index.html` with your actual DonutClient download/release URL.
2. Change Minecraft/Fabric version text if your client targets a different version.
3. Replace the mock client preview with your own screenshot if desired.
4. Upload the three files to any static host (GitHub Pages, Cloudflare Pages, Netlify, etc.).

This template does not copy Goobaa's artwork or assets.
