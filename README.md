# DonutClient Website

Blue DonutSMP-focused landing page for DonutClient / Fabric 1.21.11.

## Download link

Edit `script.js`:

- `owner` — GitHub owner
- `repo` — GitHub repository
- `releaseTag` — release tag, currently `T`
- `assetName` — JAR filename, currently `DonutClient-1.21.11.jar`

The site automatically builds the direct GitHub release asset URL:
`https://github.com/zav001/534rkyoj34oiy/releases/download/T/DonutClient-1.21.11.jar`

A `/releases/tag/T` URL is the release page, not the direct JAR download. GitHub documents the direct asset pattern as `/releases/download/<tag>/<asset-name>`.
